The module is split into two layers: top-level handlers (`exchange.ts`, `register.ts`, `exercises.ts`) orchestrate business flows, while `tools/` holds stateless utilities. Authentication follows a three-step pipeline — timestamp validation, HMAC signature verification over `email:timestamp`, then user lookup or creation — with all error cases surfaced through the typed `MobileAuthError` class. JWT tokens are created/verified via `jose` (HS256) in `tools/jwt.ts`. Data access goes exclusively through the shared Prisma singleton from `@/tools/db`; `exercises.ts` implements cursor-based pagination with a fixed PAGE_SIZE of 20, projecting related muscle groups and images. The `tools/user.ts` layer wraps Prisma queries with a consistent `USER_SELECT` shape and uses `$transaction` to atomically create a user, default `userInfo`, and pre-seeded `equipment` with rig types and requirements.
