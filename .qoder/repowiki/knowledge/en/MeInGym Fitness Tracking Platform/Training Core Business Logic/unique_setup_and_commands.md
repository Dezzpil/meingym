Tests run with Node's built-in `node:test` runner using `tsx` for TypeScript execution (`npm run test:core`, with `test:core:progression`, `test:core:progression1`, `test:core:progression2` for single progression scenarios); core tests live under `src/tests/core/`. No external service is needed: training time is estimated by `TrainingTimeAvgScorer` from fixed per-purpose norms. `TrainingTimeMLScorer` would require a local prediction service on `TIME_SCORER_PORT` (default 5001) accepting NDJSON POST requests at `/predict`, but it is not called anywhere in the app.
