Feature-sliced under src/app/weights following the project's convention of colocating page-level logic. `actions.ts` is a server-only entry (`"use server"`) exposing two mutations — `handleWeightSave` (creates a Weight row) and `handleWeightDelete` (deletes today's entry using `getCurrentDayBorders` for date scoping). `form.tsx` is a React client component (`"use client"`) built with react-hook-form that calls the save action and surfaces errors. `panel.tsx` is a read-only client component displaying the current day's weight with a delete trigger wired to the same server action. All mutations redirect back to `/` after completion, keeping state in sync without explicit revalidation. The module depends only on shared tools (`@/tools/auth`, `@/tools/db`, `@/tools/dates`) and Prisma's generated `Weight` type.
