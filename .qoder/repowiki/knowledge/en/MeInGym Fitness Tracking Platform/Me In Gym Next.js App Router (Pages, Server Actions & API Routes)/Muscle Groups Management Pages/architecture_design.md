Built as a Next.js App Router feature module under src/app/musclesgroups/. The root page.tsx lists all MuscleGroup records (with included Muscle relations) and conditionally renders an admin-only create link. The [id]/ route fetches a single group with nested MuscleGroupDesc and Muscle relations (including AgonyInActions/SynergyInActions), rendering read-only lists plus admin-only forms via MuscleGroupsDescForm and MusclesGroupsButtons components. The create/ sub-route guards access by checking UserRole.ADMIN and redirects to /404 otherwise. All mutations are implemented as Server Actions in actions.ts files: handleMuscleGroupDelete, handleMuscleGroupAddDesc, handleMuscleGroupUpdateDesc, handleMuscleGroupDeleteDesc, and handleSubmitAction. Data access goes through the shared Prisma singleton from @/tools/db, and user identity is resolved via getCurrentUser() from @/tools/auth. Zod schemas define form field types in types.ts and inline within actions.ts, with revalidatePath used after mutations instead of traditional API routes.
