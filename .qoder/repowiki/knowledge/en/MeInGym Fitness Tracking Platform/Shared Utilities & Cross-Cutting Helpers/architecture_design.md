Flat module of small, single-responsibility files with no internal dependencies between them except `auth.ts` which imports the Prisma singleton from `db.ts`. `types.ts` centralizes shared TypeScript types (`PrismaTransactionClient`, `ServerActionResult`, page param shapes). `db.ts` exports a single `PrismaClient` instance following the project's singleton pattern. `auth.ts` configures NextAuth with a single `CredentialsProvider` (email + bcryptjs password check) and JWT sessions (`maxAge` 30 days); the `PrismaAdapter` and the GitHub/Google provider blocks are commented out behind `ENABLE_OAUTH = false` and must be kept for the planned switch back to OAuth (the `VkProvider` import is live but never referenced in any provider list), while `getCurrentUser()` (React `cache()`), `getCurrentUserId()`, `findUserInfo()` (lazily creates the `UserInfo` row) and `setupNewUser()` helpers live in the same file. `fetch.ts` provides client-side `postApi` and `useApi` React hook for JSON APIs. The remaining files (`action.ts`, `dates.ts`, `func.ts`, `math.ts`, `purposes.ts`) are pure functions with no side effects, imported by other layers via the `@/*` path alias.
