Flat module of small, single-responsibility files with no internal dependencies between them except `auth.ts` which imports the Prisma singleton from `db.ts`. `types.ts` centralizes shared TypeScript types (`PrismaTransactionClient`, `ServerActionResult`, page param shapes). `db.ts` exports a single `PrismaClient` instance following the project's singleton pattern. `auth.ts` configures NextAuth with GitHub/Google/VK providers via `@next-auth/prisma-adapter` and exposes `auth()`, `getCurrentUser()`, `getCurrentUserId()`, and `findUserInfo()` helpers. `fetch.ts` provides client-side `postApi` and `useApi` React hook for JSON APIs. The remaining files (`action.ts`, `dates.ts`, `func.ts`, `math.ts`, `purposes.ts`) are pure functions with no side effects, imported by other layers via the `@/*` path alias.
