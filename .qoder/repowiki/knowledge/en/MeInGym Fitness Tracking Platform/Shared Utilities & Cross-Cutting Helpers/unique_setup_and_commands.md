Web login works without OAuth credentials: `auth.ts` uses a `CredentialsProvider`, and the GitHub/Google variables (`GITHUB_APP_ID`/`GITHUB_SECRET`, `GOOGLE_CLIENT_ID`/`GOOGLE_CLIENT_SECRET`) become required only if `ENABLE_OAUTH` is switched back to `true`. `NEXTAUTH_SECRET` and `NEXTAUTH_URL` (dev port 3005) are required. The Prisma singleton in `db.ts` must be initialized before any auth or DB operations; Docker runs PostgreSQL on host port :5435 and Redis on :6379 as prerequisites.
