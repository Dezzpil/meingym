The repository is organized into layered modules under src/ with a clear separation of concerns: core holds pure business logic (training scoring, difficulty, progression) with no HTTP dependencies; app implements the Next.js App Router layer wiring feature modules to Prisma via server actions and REST-style API routes; jobs runs Bull workers against Redis for async score calculation, period checks, and image cleanup; tools provides cross-cutting utilities (Prisma singleton, NextAuth config, HTTP helpers); components delivers shared React UI primitives; mobile exposes HMAC-authenticated endpoints for external clients; scripts and tests are standalone Node/tsx runners. All modules share a single PrismaClient instance exported from tools/db.ts, use the @/* path alias for imports, and depend on the same PostgreSQL database and Redis broker orchestrated by docker-compose.yml.
