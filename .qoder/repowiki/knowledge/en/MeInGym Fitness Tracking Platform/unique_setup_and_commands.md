Development uses `npm run dev` on port 3005 (`NEXTAUTH_URL` in `.env.local` must match); database migrations via `npm run prisma:migrate` (dotenv-cli loads `.env.local`); background workers started with `npm run workers`; tests are split per layer — `npm run test:core`, `test:mobile`, `test:mobile-auth`, `test:tools` (there is no combined `npm test`); maintenance scripts run through the same `node --import tsx` pattern (`update-actions`, `update-personal-records`, `collect-exercise-time`, `create-equip-for-users`, `mobile-auth-test`). Docker Compose provisions PostgreSQL (host port :5435) and Redis (:6379) with persistent volumes under ./data/. Release workflow uses standard-version with patch/feature/breaking variants.
